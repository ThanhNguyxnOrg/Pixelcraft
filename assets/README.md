## Palette

Representative colors sampled from the supplied artwork, not semantic UI tokens:

| Color | Hex | Role in the artwork |
|---|---|---|
| Midnight navy | `#01072A` | Theme background |
| Deep navy | `#020835` | Logo outlines and inner field |
| Electric cyan | `#03F0ED` | Code glyph and cool highlights |
| Bright blue | `#028BF3` | Cool-side shading |
| Violet | `#6E25FA` | Gear and transition accents |
| Neon magenta | `#F908F5` | Warm-side gear highlights |
| Signal orange | `#FC9126` | Upper-right pixel accents |

Keep the transparent logo on a background that separates its navy silhouette. Treat the bright colors as accents, and check contrast for any text or controls that use them.
