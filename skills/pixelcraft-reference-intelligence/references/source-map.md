# Creative reference source map

Use each source for the kind of evidence it is good at. Availability, taxonomy, and access rules can change; verify current pages before relying on them.

| Source | Best use | Entry points |
|---|---|---|
| Awwwards | Site of the Day/Month/Year, technical tags, elements, collections, studio/project details | https://www.awwwards.com/websites/sites_of_the_day/ · https://www.awwwards.com/websites/sites_of_the_month · https://www.awwwards.com/websites/sites_of_the_year |
| CSS Design Awards | WOTD/WOTM/WOTY, UI/UX/innovation judging, feature and industry taxonomy | https://www.cssdesignawards.com/wotm-award-winners · https://www.cssdesignawards.com/woty-award-winners |
| The FWA | Digital experiences, experiential projects, interactive/web categories, project narratives | https://thefwa.com/ |
| Recent (formerly Godly entry point) | Current web/interface/branding/motion/illustration/print inspiration | https://recent.design/ · legacy entry point: https://godly.website/ |
| Lapa Ninja | Landing pages and individual sections: hero, pricing, proof, CTA, footer, interaction examples | https://www.lapa.ninja/ |
| Mobbin | Shipped app screens, flows, onboarding, settings, commerce, web/mobile product UX | https://mobbin.com/ |
| Land-book | Websites, sections, mobile layouts, motion, OG images, headlines | https://land-book.com/ |
| SiteInspire | Typography, layout, art direction, portfolio, commerce, photography, minimal composition | https://www.siteinspire.com/ |
| One Page Love | Single-page sites, landing pages, launch pages, section inspiration | https://onepagelove.com/ |

## Source role separation

- Awards are discovery and evaluation sources, not a universal definition of quality.
- Section galleries are useful for composition and content modules, not application behavior.
- Product-flow libraries are useful for task flows, states, and shipped UX, not necessarily for brand art direction.
- Live projects provide the strongest interaction evidence, but may be inaccessible, changed, or technically opaque.
- Keep calm, fast, accessible product references alongside high-expression portfolio/campaign work.
