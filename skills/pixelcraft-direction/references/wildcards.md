# Subject-derived wildcard generators

Use these generators when the movement catalog itself starts becoming a monoculture. A wildcard must still satisfy mode, floor, and platform constraints.

## Constraint dice

Pick one item from three different columns, then justify each through the subject:

| Material/structure | Visual operation | Information behavior |
|---|---|---|
| ledger/index/archive | rotate one axis 2–8 degrees | reveal detail through measurement/annotation |
| instrument/control panel | crop aggressively | prioritize live state over persuasion |
| field notebook/map | repeat a module with controlled irregularity | layer primary/secondary/tertiary reading |
| packaging/label/system | translate physical print artifact digitally | use comparison rather than cards |
| stage/score/choreography | use strict horizontal/vertical rhythm | sequence information by time/state |
| organism/terrain/weather | let content determine aspect ratio | expose uncertainty/range explicitly |
| machine protocol/log | use tabular or monospaced precision | make state transitions visible |
| game/manual/signal system | use pictograms as a real system | teach through progressive disclosure |

## Subject questions

Answer with concrete artifact evidence:

1. What physical object, document, instrument, place, organism, or ritual already embodies the subject?
2. What units, scales, symbols, constraints, or failure modes does the domain use?
3. What would an expert notice that a generic observer misses?
4. What material contrast is native to the domain (rough/precise, ephemeral/permanent, hot/cold, dense/sparse)?
5. What is the wrong cultural stereotype for this subject? Exclude it explicitly.
6. Which sense other than sight has a visual analog: rhythm, weight, texture, temperature, proximity, sequence?

## Transformation operators

Apply one or two, never all:

- invert hierarchy: make metadata or mechanism the hero;
- change scale: macro texture, microscopic detail, architectural overview;
- change time: freeze a process, show provenance, expose a state machine;
- change perspective: cross-section, exploded view, plan view, operator view;
- change medium: blueprint, label, ledger, score, signal, field guide, control strip;
- impose a numerical constraint: two colors, one radius, one axis, 7-column grid, no rectangles;
- localize deeply: derive from the audience's visual vernacular rather than exported US/European SaaS taste.

## Anti-monoculture rules

- If two consecutive directions share composition family, force the next wildcard to use a different axis of contrast.
- Never use a random aesthetic without a subject rationale.
- A wildcard is successful only if removing the subject would make the design explanation stop making sense.
