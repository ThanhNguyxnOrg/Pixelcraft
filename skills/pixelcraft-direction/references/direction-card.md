# Direction card template

Use this compact artifact as the bridge between divergence and implementation.

```markdown
# Direction: <name>

**Concept:** <one sentence tying subject/material to visual behavior>
**Mode/surface:** <mode, platform, input modality, density>
**Ambition tier & probability class:** <Pragmatic High-Craft / Editorial Domain-Object / Bold Experimental; high/medium/low conventional-model probability>

## Structural skeleton (ASCII)
```text
<compact region wireframe showing focal anchor, navigation shape, signature element placement, and narrow/mobile adaptation note — required so implementation cannot collapse to default hero+3-cards>
```

## Real-copy lead draft
- Primary headline / screen title: <concrete domain-language draft — zero AI clichés or lorem ipsum>
- Supporting lead / summary: <1 concrete factual line grounded in brief material>
- Primary action(s): <exact consequence-naming verb labels, e.g. "Log core sample", "Compare 2025 filings">

## Composition
- Grid/structure: <columns, asymmetry, alignment, measure, spatial logic>
- Density: <compact/comfortable/sparse; where it changes>
- Hierarchy: <primary scan path and first commitment>

## Typography
- Voice: <editorial/instrumental/human/etc.>
- Roles: <display/body/UI/data/caption behavior>
- Script/localization: <coverage, fallback, numerals, line breaking risks>

## Color and material
- Posture: <light/dark/chromatic/neutral; symbolic or physical rationale>
- Semantic roles: <surface/ink/accent/state/data roles>
- Material/texture/depth: <paper/metal/glass/terminal/flat/etc.; constraints>

## Motion
- Purpose: <orientation, feedback, causality, measurement, play>
- Posture: <durations/easing/choreography>
- Reduced path: <instant/static/opacity-only alternative>

## Imagery and icons
- Source/provenance: <real assets, generated, diagrammatic, none>
- Rules: <crop, treatment, color, aspect, density>
- Icon system: <metaphor family, stroke/fill, optical size>

## Signature element
<one memorable subject-derived element; where it appears; when it must quiet down>

## Explicit taboos
- <patterns forbidden because they conflict with concept or are slop fingerprints>

## Floor risks and validation plan
- Accessibility: <risk + check>
- Localization: <expansion/script/RTL risk + fixture>
- States/performance: <risk + check>
- Platform transfer: <what changes per target stack>

## Decision log
- Chosen because: <evidence>
- Lost directions: <name — reason>
```

Keep the card implementable. “Elegant,” “premium,” and “modern” are not specifications.
