# Julia Genie (adjacent data-app ecosystem)

Genie/Stipple is Julia web/data-app infrastructure, not Python. Route it here because the product shape is closest to internal data applications; verify current framework APIs because the ecosystem evolves quickly.

## Token mapping

Stipple/Genie commonly expose Vue/Quasar-style browser UI behavior. Map tokens through theme/configuration and generated CSS variables rather than mutating autogenerated internals. Keep Julia-computed constants synchronized via token export or explicit semantic mapping.

## Layout and responsive idioms

Use server-defined pages/layout/components plus responsive browser layout. Distinguish static content, reactive dashboard regions, and API-backed interactions. Do not treat every dashboard as a blank reactive canvas.

## Typography/custom fonts

Load fonts in page assets/templates with fallback/subsets. Verify numeric/tabular legibility, plot/UI font consistency, scaling/localization, initial server render behavior.

## Motion/reduced motion

Use CSS/component-level motion sparingly and respect `prefers-reduced-motion`. Reactive loading indicators must represent actual server/computation state rather than decorative spinners.

## Accessibility specifics

Use semantic generated HTML/components, labels, keyboard/focus behavior, text summaries for plots/tables, non-color encoding, error announcements. Julia backend correctness does not prove browser accessibility; inspect emitted DOM.

## States idiom

Model loading/empty/error/permission/offline/stale/reactive-disconnect states explicitly. Long Julia computations need task ownership, cancellation/timeout expectations, progress feedback, cache invalidation, and multi-user isolation.

## Forms idiom

Use real labeled inputs/browser validation plus server validation. Preserve inputs across reactive updates/failed submit; use correct keyboard/paste/IME behavior and field-level recovery copy. Uploaded data needs type/size/security constraints.

## Do/don't pairs

| Do | Don't |
|---|---|
| semantic theme/CSS variables | brittle overrides of generated component internals |
| explicit empty-vs-error branches | blank chart when query fails |
| labeled reactive inputs | controls that reset on unrelated invalidation |
| server task progress/error state | fake spinner disconnected from computation |

## Known traps

Version/API drift, reactive round-trip latency, hidden state shared across users, long-running task blocking, plot/theme mismatch, browser accessibility neglect, deployment resource limits.

## Verification commands

```sh
julia --project -e 'using Pkg; Pkg.test()'
julia --project app.jl
npx playwright test
```

Inspect browser DOM/rendering, concurrent sessions, network loss/reconnect, empty/error/large data, keyboard/focus behavior, text scaling/localization, production resource limits.
