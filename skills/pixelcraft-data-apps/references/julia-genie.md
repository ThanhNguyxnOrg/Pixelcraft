# Julia Genie / Stipple

Genie and Stipple provide reactive Julia web/data-app infrastructure built over Vue/Quasar browser components. Keep reactive idioms native to Julia (`GenieFramework`) rather than porting Python patterns literally.

## Token mapping

Stipple renders Quasar/Vue components in the browser. Configure theme colors and typography through `public/css/` custom stylesheets (semantic CSS variables and Quasar brand overrides `--q-primary`, `--q-dark-page`) rather than mutating autogenerated component internals. Keep Plotly/Makie chart palettes synchronized with page tokens explicitly.

## Reactive `@app` idiom (`@in`, `@out`, `@private`, `@onchange`)

Declare every reactive variable's direction explicitly: `@in` is browser-writable, `@out` is server-to-browser read-only, and `@private` stays strictly server-side (never serialized over WebSocket to the browser).

```julia
module OpsApp
using GenieFramework, DataFrames, PlotlyBase
@genietools

@app begin
    @in region = "EMEA"
    @in run_trigger = false
    @out regions = ["EMEA", "AMER", "APAC"]
    @out loading = false
    @out error_msg = ""
    @out rows = DataTable(DataFrame(order_id = String[], revenue = Float64[]))
    @private db_pool = init_db_pool()  # never serialized to client

    @onchange isready, region, run_trigger begin
        loading = true
        error_msg = ""
        try
            df = query_orders(db_pool, region)
            rows = DataTable(df)
        catch err
            error_msg = sprint(showerror, err)
            rows = DataTable(DataFrame(order_id = String[], revenue = Float64[]))
        finally
            loading = false
        end
    end
end

function ui()
    [
        row(class = "q-pa-md items-center q-gutter-md", [
            select(:region, options = :regions, label = "Region", outlined = true),
            btn("Refresh", color = "primary", @click("run_trigger = !run_trigger"), loading = :loading),
        ]),
        p("{{error_msg}}", class = "text-negative q-px-md", @if("error_msg != ''")),
        p("No orders match this region.", class = "q-px-md", @if("!loading && error_msg == '' && rows.data.length === 0")),
        table(:rows, flat = true, bordered = true),
    ]
end

@page("/", ui)
end
```

## Layout, typography, motion, and accessibility

Compose responsive views with Quasar flex/grid helpers (`row`, `cell`, `col-12 col-md-6`) instead of fixed pixel widths. Load custom fonts via `public/css/` with fallbacks and `tabular-nums` on numeric cells. Bind `loading = :loading` truthfully to server computation and honor `prefers-reduced-motion` in custom CSS. Because Stipple emits Vue/Quasar DOM, inspect actual browser labels, keyboard reach, focus order, contrast, and text/table alternatives for plots.

## States and concurrency idiom

- Keep mutable per-user state inside `@app` reactive models (instantiated per session); never mutate module-global `DataFrame`s shared across sessions.
- Keep database handles, tokens, and large intermediate matrices in `@private` fields so they never serialize over WebSocket.
- Offload long scientific/optimization runs with `Threads.@spawn` / async channels so WebSocket heartbeats remain responsive, and surface timeout/error branches cleanly.

## Do/don't pairs

| Do | Don't |
|---|---|
| `@in` for user inputs, `@out` for read-only outputs, `@private` for server objects | Exposing server handles or large raw arrays as `@in`/`@out` |
| Explicit `loading`, `error_msg`, and empty-table UI branches | Leaving an empty table or stuck spinner when a query throws |
| Per-session `@app` state with `try/catch/finally` | Mutating module-level globals across concurrent sessions |
| Semantic CSS vars in `public/css/` synced with Plotly/Makie themes | Brittle overrides of generated Quasar internals |

## Known traps

Serializing huge DataFrames or secrets via `@out` instead of `@private`, blocking Genie worker threads on unspawned scientific compute, Julia first-plot/TTFX cold latency without precompilation/PackageCompiler, plot/dark-mode theme mismatch, and mutating shared module globals.

## Verification commands

```sh
julia --project -e 'using Pkg; Pkg.test()'
julia --project app.jl
npx playwright test
```

`Pkg.test()` validates Julia data and handler logic (`static`/unit evidence); browser/Playwright inspection across narrow viewports, concurrent sessions, error paths, and reconnects provides `rendered` evidence.
