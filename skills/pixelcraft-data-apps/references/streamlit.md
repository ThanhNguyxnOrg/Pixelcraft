# Streamlit

## Token mapping

Configure `.streamlit/config.toml` first using `[theme]`, `[theme.sidebar]`, and light/dark sections (`primaryColor`, `backgroundColor`, `secondaryBackgroundColor`, `textColor`, `linkColor`, `font`, `fontFaces`, `baseFontSize`, chart palettes):

```toml
[theme]
base = "light"
primaryColor = "#0074ca"
backgroundColor = "#faf8f1"
secondaryBackgroundColor = "#f1eee4"
textColor = "#161b24"
linkColor = "#005a9e"
```

Map semantic tokens deliberately; primary color alone is not a design system. Reach for scoped custom CSS only when `.streamlit/config.toml` cannot express a structural requirement, and never rely on autogenerated emotion/st-emotion class hashes.

## Layout, navigation, and responsive idioms

Use `st.navigation` with `st.Page` for multipage apps so shared chrome, auth gates, and global filters live in one entrypoint instead of fragile `pages/` filename sorting:

```python
import streamlit as st

nav = st.navigation({
    "Analytics": [
        st.Page("views/overview.py", title="Overview", default=True),
        st.Page("views/cohorts.py", title="Cohorts"),
    ],
    "Operations": [st.Page("views/audit.py", title="Audit Log")],
})
nav.run()
```

Size dataframes, charts, buttons, and containers with `width="stretch"` or `width="content"` (or an explicit pixel integer) rather than the deprecated `use_container_width` argument:

```python
st.dataframe(df, width="stretch", hide_index=True)
st.plotly_chart(fig, width="stretch")
st.button("Export CSV", width="content")
```

Avoid deeply nested `st.columns` that crush on narrow viewports. Keep `st.sidebar` focused on controls or navigation, never overloaded with both.

## Caching, connections, fragments, and chat

Separate serializable data caching from singleton resource caching, isolate high-frequency subtrees with `@st.fragment`, and stream conversational responses with `st.chat_message` + `st.write_stream`:

```python
import streamlit as st

conn = st.connection("warehouse", type="sql")

@st.cache_data(ttl=300, show_spinner="Loading daily metrics...")
def load_metrics(region: str):
    return conn.query(
        "SELECT day, revenue FROM daily_metrics WHERE region = :region",
        params={"region": region},
    )

@st.cache_resource
def load_model():
    return init_heavy_embedding_model()

@st.fragment
def live_filter_panel():
    region = st.selectbox("Region", ["EMEA", "AMER", "APAC"], key="region")
    df = load_metrics(region)
    if df.empty:
        st.info("No rows for this region.")
        return
    st.dataframe(df, width="stretch")

with st.chat_message("assistant"):
    st.write_stream(stream_answer_chunks(prompt))
```

- Use `@st.fragment` (and optional `run_every="30s"` for polling) so interacting with one chart or table does not rerun the whole script. Call `st.rerun(scope="app")` only when a fragment must update outer state.
- Use `st.components.v2` (`st.components.v2.component`) for new bidirectional custom web components that need direct DOM/CSS integration and typed state hooks instead of legacy iframe-only v1 wrappers.

## Typography, motion, and accessibility

Use `fontFaces` / `baseFontSize` in `.streamlit/config.toml` for typography. Use `st.status`, `st.progress`, and `st.toast` truthfully for long-running work; custom CSS animation must honor `prefers-reduced-motion`. Always provide widget labels (use `label_visibility="collapsed"` rather than empty `""` so screen readers keep accessible names), pair charts with text takeaways or expandable data tables, and verify keyboard navigation and contrast in rendered output.

## Forms and states idiom

Every interaction triggers a rerun of either the fragment or the script. Initialize `st.session_state` explicitly, use stable `key`s, and wrap multi-field mutations in `st.form` so intermediate edits do not trigger expensive queries. Distinguish empty datasets (`df.empty`), missing credentials/secrets, validation errors, and stale cached results visibly.

## Do/don't pairs

| Do | Don't |
|---|---|
| `st.dataframe(df, width="stretch")` / `width="content"` | Deprecated `use_container_width=True` |
| `@st.fragment` around interactive filters or polling widgets | Rerunning expensive top-level setup on every filter change |
| `st.cache_data(ttl=...)` for DataFrames; `st.cache_resource` for models/connections | Storing per-user mutable state in global `st.cache_resource` |
| `st.navigation([st.Page(...)])` for shared multipage framing | Duplicating auth and sidebar boilerplate across `pages/*.py` |
| `st.connection(...)` with parameterized SQL queries | Interpolating widget values directly into SQL strings |
| `st.status(..., expanded=True)` reflecting real execution steps | Fake progress bars or silent spinners after an exception |

## Known traps

Full-script reruns wiping unkeyed inputs, duplicate widget keys, mutating objects returned from `st.cache_resource` across sessions, leaking secrets into client state, brittle `.st-emotion-cache-*` CSS selectors, sidebar overload, and uploaded `UploadedFile` buffers not rewound (`seek(0)`) on reread.

## Verification commands

```sh
python -m compileall .
python -m pytest
streamlit run app.py
```

Write headless state and interaction tests with `streamlit.testing.v1.AppTest` (`AppTest.from_file("app.py").run()`) as `static`/logic evidence, and run Playwright or manual browser checks across narrow/desktop widths for `rendered` evidence.
