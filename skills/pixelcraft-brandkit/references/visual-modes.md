# Visual modes

Choose a mode from strategy, category, audience, emotional promise, and trust requirements. Modes are starting systems, not fixed skins. During divergence, select different modes or materially different interpretations of a mode.

## 1. Dark Developer / Builder

**Use for:** developer tools, coding agents, infrastructure, automation, AI builders.

**Visual cues:** near-black panels; monospace accents; command lines; terminal windows; prompt bars; subtle grid; cyan, blue, coral, or lime accents; pixel/CRT texture when appropriate.

**Logo logic:** cursor + frame; bolt + build speed; scaffold + monogram; terminal glyph + symbol; modular construction mark.

**Mood:** precise, sharp, confident, builder-native.

## 2. Dark Product / Operator

**Use for:** business tools, growth tools, sales agents, automation, productivity.

**Visual cues:** black/dark red/amber; glowing UI chips; card systems; segmented flows; icon rows; reward/progress motifs; minimal hero text.

**Logo logic:** signal, gift, path, operator mark, switch, loop, command system.

**Mood:** fast, operational, tactical, premium.

## 3. Dark Nature / Calm System

**Use for:** strategy, travel, wellness, climate, quiet premium SaaS.

**Visual cues:** deep green; lime accent; misty landscapes; image/UI circles; soft overlays; calm page labels; dark editorial grid.

**Logo logic:** path, leaf, moon, horizon, compass, portal, folded mark.

**Mood:** calm, trustworthy, focused.

## 4. Dark Security / Threat Intelligence

**Use for:** security, compliance, monitoring, network products.

**Visual cues:** black/navy; shield forms; radar lines; threat labels; subtle motion traces; red/blue alert chips; controlled gradients.

**Logo logic:** shield, raptor, eye, watch, boundary, protected core.

**Mood:** serious, vigilant, precise.

## 5. Light Editorial / Compliance

**Use for:** legal, privacy, compliance, documents, trust brands.

**Visual cues:** warm ivory; paper texture; small serif labels; seals/badges; color wheel/palette object; calm stationery; deep blue, red, gold accents.

**Logo logic:** seal, dog, shield, document, stamp, monogram.

**Mood:** trustworthy, refined, institutional but modern.

## 6. Luxury / Beauty / Fashion

**Use for:** beauty, fashion, hospitality, premium services.

**Visual cues:** ivory/stone/espresso; serif wordmark; elegant monogram; paper grain; embossing; product labels; editorial crops; soft shadows.

**Logo logic:** monogram, seal, petal, vessel, ritual object, refined typographic mark.

**Mood:** tasteful, adult, expensive.

## 7. Voice / Communication

**Use for:** voice AI, chat, assistants, speech, audio.

**Visual cues:** dark indigo; lilac glow; waveform; mic motif; phone crop; command input; app icon.

**Logo logic:** wave + initial; sound orb; speech path; microphone abstraction; pulse ring.

**Mood:** fluid, intelligent, intimate.

## 8. Cultural / Experimental

**Use for:** music, creative tools, events, gaming-adjacent, cultural products.

**Visual cues:** halftone; CRT texture; analog print; bold accent color; poster-style panels; unexpected image crops; simple punchy logo.

**Logo logic:** custom wordmark; icon with attitude; symbolic mascot; print-inspired mark.

**Mood:** memorable, creative, still controlled.

## 9. Bright Consumer / Playful

**Use for:** consumer apps, social products, creator tools, family products, casual games, learning products with high energy.

**Visual cues:** warm white or tinted canvas; saturated but limited accent pair; rounded geometry; sticker/badge system; expressive app icon crops; joyful object photography; simple oversized type; paper-cut or soft 3D detail.

**Logo logic:** smile/path/monogram fusion; mascot reduced to a symbol; playful geometric initial; reward/coin/star only when meaningful.

**Mood:** accessible, energetic, optimistic, controlled rather than childish.

## 10. Industrial / Hardware

**Use for:** robotics, devices, manufacturing, automotive, infrastructure hardware, field tools, sensor systems.

**Visual cues:** graphite/titanium/safety-color accents; machined texture; measurement marks; exploded-object crops; rugged labels; chassis/panel details; blueprint or CAD overlays; precise modular grids.

**Logo logic:** enclosure edge; fastener/slot abstracted; wing/sensor/beam; coordinate path; stamped monogram; functional geometric seal.

**Mood:** durable, exact, engineered, mission-capable.

## 11. Health / Care

**Use for:** healthcare, clinical workflow, mental health, care coordination, accessibility products, wellness requiring trust rather than luxury escapism.

**Visual cues:** soft neutral base; calm blue/green/coral accents; generous whitespace; human-scale photographic crops without stock cliché; rounded but restrained forms; clear type specimen; gentle wayfinding motifs; privacy-safe UI fragments.

**Logo logic:** protected figure abstracted; pulse/path; hand/holding shape reduced geometrically; cross only where legally/culturally appropriate; care loop; calm monogram.

**Mood:** safe, humane, clear, dependable.

## 12. Fintech / Trust

**Use for:** banking, payments, treasury, insurance, accounting, risk, compliance-heavy financial products.

**Visual cues:** deep navy/ink/ivory or restrained bright base; precise rules; ledger/grid motifs; secure card/vault/hardware detail; numeric typography; mint/gold/electric blue accent discipline; subtle security pattern; red/green reserved for meaning rather than decoration.

**Logo logic:** ledger line; vault/protected core; value path; bridge/architecture; initials formed from exchange/balance geometry; seal without fake heraldry.

**Mood:** exact, credible, calm, institutionally strong without feeling antique.
