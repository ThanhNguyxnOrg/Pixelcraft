# Logo concept methods

Apply these methods only when a new logo is needed or explicitly requested. Existing supplied logos must be reused rather than reinterpreted.

## Strategy-to-symbol logic

Infer category, audience, product function, emotional promise, cultural position, trust level, visual world, symbolic metaphor, and explicit anti-goals before sketching. Use domain meaning, not random icon association.

| Category | Core ideas | Possible symbol logic |
|---|---|---|
| Developer tool | building, precision, composition, control | bracket, frame, modular block, scaffold, grid |
| AI assistant | delegation, synthesis, clarity | signal, conduit, path, node, lens |
| Security | protection, vigilance, boundary | shield, aperture, seal, protected core |
| Interactive / games | rules, momentum, play, craft | token, tile, emblem, crest, geometric pawn |
| Voice / audio | sound, rhythm, clarity, flow | waveform, acoustic slit, mic grille, speech path |
| Compliance / legal | trust, order, verification, record | seal, stamp, folded document, ledger mark, shield |
| Robotics / aerospace | flight, guidance, sensing, precision | airfoil, reticle, vector path, horizon, chassis cut |
| Craft / editorial | material, proportion, permanence, restraint | monogram, blind emboss, colophon, registration mark |
| Productivity | focus, sequence, completion, clarity | path, check, modular grid, index tab, compass |

These are starting hypotheses, not mandatory clip art.

## Logo generation standard

The logo must be simple, memorable, symbolic, scalable, ownable, visually balanced, connected to the brand strategy, and usable as icon, wordmark, badge, UI mark, and pattern. It should read as the output of research and reduction.

Avoid generic lightning bolts, random animals, glowing orbs, fake luxury crests, copied famous marks, overcomplicated symbols, clipart-style icons, meaningless sparkles, inconsistent logo variants, and generic initial-in-a-box marks.

Use one method below, or combine at most two.

## 1. Monogram + meaning

Combine the brand initial with a structural metaphor derived from the product:

- initial + directional fold / architectural corner
- initial + continuous path / conduit
- initial + acoustic wave / rhythmic bar
- initial + split bracket / modular frame

Do not make a plain letter inside a square. Use negative space, cuts, folds, modular geometry, directional stress, or interlocking forms.

## 2. Product action

Turn the product's main action into a reduced geometric symbol:

- build → frame, scaffold, modular block, interlocking joint
- protect → shield, boundary seam, watch reticle
- convert → switch, split arrow, transformation fold
- speak → waveform, acoustic grille, resonance bar
- monitor → aperture, radar sweep, calibrated trace
- automate → continuous loop, relay node, handoff path

Keep forms geometric and reductive, not literal illustration or clipart.

## 3. Metaphor fusion

Combine two domain-specific ideas into one reduced mark:

- protective boundary + architectural pillar (security / trust)
- horizon line + compass needle (navigation / travel)
- modular grid + speech bracket (collaborative tooling)
- folded ledger page + verification notch (audit / finance)
- acoustic wave + letterform stem (audio / communications)
- lens aperture + coordinate crosshair (optical / spatial hardware)

The fusion must be subtle and readable at `16–24 px`. If it requires a paragraph to explain, simplify.

## 4. Negative space

Use empty space to create intelligence:

- hidden arrow
- protected center
- cutout initial
- internal path
- folded corner
- eye formed by crossing shapes

Negative space should be crisp and intentional, not accidental ambiguity.

## 5. Construction geometry

Create a mark from a clear system using circles, diagonal cuts, grids, frames, modular blocks, layered cards, orbital paths, crosshairs, or measured linework. One panel can show construction logic. Geometry must explain the mark rather than decorate it.

## System behavior

A professional logo concept includes consistent behavior across:

- primary symbol;
- wordmark spacing/case;
- app/icon crop;
- badge/seal variant where appropriate;
- small-size simplification;
- pattern/system detail;
- construction/negative-space logic.

Do not let each panel invent a different mark.
