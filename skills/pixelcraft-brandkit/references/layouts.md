# Brand board layouts and art direction

## Default output and canvas handling

Unless the user specifies otherwise:

- generate one brand-kit overview image;
- default layout `3 × 3`;
- default aspect ratio `4:3` or `16:10`;
- clean presentation grid, consistent gutters, minimal text, connected panels.

Canvas size/aspect ratio describes the **whole output image**, not the panel grid. Honor requested width × height, aspect ratio, or orientation over defaults. Include them in the prompt and use the generator's supported controls. If exact dimensions are unsupported, explain the limit and alternatives; preserve the requested ratio where possible; ask only when cropping/resizing/composition materially changes the result; report actual output size.

Adapt grid/spacing to square, portrait, or wide canvases without stretching panels. Keep defaults when no custom size/layout is requested.

## Board composition DNA

A strong board is a curated sequence, not nine equally loud tiles. Use rhythm across:

- quiet — large calm cover panel;
- functional — digital/product surface;
- emotional — image-led atmosphere;
- technical — system/construction;
- atmospheric — material/texture/world;
- detailed — chips/icons/pattern/detail.

Include negative space and strong gutters. Details should reward closer inspection: page numbers, tiny footer labels, alignment marks, construction lines, subtle crosshair grids, thin rules, browser bars, image masks, soft shadows, low-opacity texture, one highlighted word, one accent chip, or one strong icon state. Do not overuse them.

## `3 × 3` full identity system

Use when no layout is specified and it fits the canvas:

1. **Logo cover** — large logo/wordmark, minimal title, strong negative space.
2. **Logo construction** — symbol breakdown, grid, geometry, negative-space logic; for existing logos without documented construction, show supplied variants or correct usage instead.
3. **Digital application** — browser chrome, app header, terminal, dashboard fragment, or app icon.
4. **Brand essence** — one short tagline, large readable typography, sparse composition.
5. **Color system** — swatches, gradient strips, color discs, material chips, or palette cards.
6. **Typography** — large specimen, alphabet row, or primary/secondary pairing.
7. **Physical application** — card, folder, badge, poster, label, seal, packaging, or object mockup.
8. **Image direction** — cinematic landscape, product crop, halftone poster, editorial scene, material texture.
9. **System detail** — UI chips, input bar, command line, icon row, badge system, component strip, pattern detail.

## `2 × 3` cinematic brand deck overview

Use for premium mini-deck/reference-style rhythm:

1. **Logo / wordmark** — centered or offset, extremely minimal.
2. **Browser / product surface** — browser bar, app frame, prompt input, URL field.
3. **Command / functional panel** — terminal, prompt bar, input state, install command, dashboard fragment.
4. **Atmosphere / campaign image** — halftone landscape, cinematic image, product-world visual, art-directed photo.
5. **Symbol / construction / badge** — mark in target, seal, geometric frame, icon construction.
6. **Tagline / system promise** — one short line, large type, quiet background.

## `2 × 2` compact concept board

Use for a focused concept with fewer artifacts: logo cover, construction/system logic, one strongest application, one image/essence panel. It should feel decisive rather than like a cropped full system. Increase panel scale and negative space.

## `1 × 3` horizontal brand strip

Use for wide/social/banner outputs: left/logo or essence, center/application or atmosphere, right/system detail or palette. Maintain a strict shared baseline/height. Avoid compressing nine-panel content into three unreadable panels.

## `4 × 2` wide contact-sheet layout

Use for comparing system behavior across eight controlled panels: cover, construction, type, palette, digital application, physical application, image direction, detail. Treat it as a contact sheet with strict gutters and consistent scale—not a clutter collage.

## Custom layout

When requested, preserve the same rules: one dominant idea, clear cover/anchor panel, hierarchy across panel sizes, consistent gutters, no arbitrary stretching, no equal loudness everywhere. State the panel inventory before generation.

## Text rules

Use very little text. Good text: brand name, one tagline, one URL, one command, 2–5 section labels, short UI chips. Bad text: long paragraphs, tiny fake body copy, many menu items, lorem ipsum, dense explanations, unreadable labels. Text must be large and sparse enough to render legibly.

## Tagline style

Good examples: “What will you build today?”, “Nothing random.”, “Your network. Our watch.”, “Build better.”, “On guard.”, “Every mission under control.”, “Everything operators need.”, “Clarity builds confidence.” Avoid corporate slogans, long marketing copy, buzzword soup, and fake inspirational fluff.

## Image direction

Use art-directed imagery: cinematic mountains, dusk skies, landscapes with brand overlays, halftone clouds, CRT scenes, dark product closeups, dramatic object crops, textured paper, moody architecture, abstract controlled systems. Avoid generic stock people, random offices, cliché robots, overbusy scenes, and unrelated imagery. Match palette and metaphor.

## Mockup direction

Use minimal believable applications: browser chrome, URL bar, terminal window, command prompt, app icon, phone corner crop, card stack, badge, seal, folder, UI chips, dashboard fragment, input bar, product label. Avoid fake dense dashboards, cheap gloss, device overload, busy screens, excessive icons. Mockups are identity applications, not feature demos.

## Color discipline

Use one dominant palette: base color, primary accent, secondary accent, neutrals. Reference-quality starting postures include black+cyan+muted coral; black+red+cream+blue; forest green+lime+fog gray; navy+white+steel; ivory+deep blue+red+gold; black+lilac+soft purple; black+amber+red; charcoal+white+pale blue. Accents repeat across panels. No random rainbow unless requested. No generic purple-blue AI glow unless appropriate. One accent can carry the system.
