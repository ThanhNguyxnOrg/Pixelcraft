# Marketing landing pages

Marketing pages are persuasion surfaces, not operational dashboards. They can carry stronger narrative and visual expression, but the floor still applies.

## Differences from app UI

| Marketing | App UI |
|---|---|
| orientation + memory + action | repeated efficient task completion |
| narrative sequence matters | stable dense structure matters |
| expressive composition can lead | chrome and density often lead |
| one primary conversion path | multiple parallel workflows |

Do not import dashboard cards, fake metrics, generic SaaS gradients, or app-like chrome into a persuasive page unless the direction calls for it.

## Structure

1. concrete audience/problem/context promise;
2. evidence or demonstration using truthful material;
3. differentiation and mechanism;
4. objection handling/detail;
5. clear action with expectation of what happens next.

Hero composition should come from the subject/material and direction card. The centered headline/two-button template is a fingerprint, not a default. Use real product media only when truthful and inspect its loading/fallback cost.

## Trust rules

No fake logos, testimonials, metrics, countdowns, scarcity, screenshots, awards, or personalization. Label conceptual/mock media. Pricing and comparison claims need dates/qualifiers. Forms state use of data and validation recovery.

## Verification

Test narrow/mobile reading order, long localized headlines, RTL, font fallback, image failure, reduced motion, keyboard focus through skip/nav/CTA/form, contrast over imagery, Core Web Vitals/CLS, social metadata, and offline/error states for interactive demos.
